MalerLernApp – مشروع Android للبناء السحابي
==========================================

هذا مشروع Android حقيقي يفتح واجهة التطبيق داخل WebView. يحتوي على:
- بطاقات حفظ واختبار.
- قاموس ألماني–عربي.
- حفظ التقدم محليًا عبر localStorage.
- إعداد GitHub Actions لبناء APK تلقائيًا.

طريقة البناء السحابي:
1) أنشئ مستودعًا جديدًا على GitHub باسم MalerLernApp.
2) ارفع كل ملفات هذا المشروع إلى المستودع (ارفع محتويات المجلد، لا ملف ZIP فقط).
3) افتح تبويب Actions في المستودع ووافق على تفعيل GitHub Actions إن طُلب ذلك.
4) اختر workflow: "Build MalerLernApp APK" ثم اضغط Run workflow.
   ويمكن أيضًا أن يبدأ البناء تلقائيًا عند push إلى فرع main.
5) افتح عملية البناء الناجحة، ثم من Artifacts نزّل MalerLernApp-debug-APK.zip.
6) فك ضغطه على الهاتف لتحصل على app-debug.apk، ثم افتح APK وثبّته.
7) قد يطلب Android السماح لمتصفحك/Files بتثبيت تطبيقات من هذا المصدر؛ اسمح فقط إذا كنت تثق بالمصدر الذي بنيت منه المشروع.

ملاحظات:
- الناتج Debug APK قابل للتثبيت للتجربة، لكنه ليس إصدار متجر Play موقّعًا بمفتاح نشر.
- كل البيانات التعليمية الحالية محفوظة داخل التطبيق. الأسئلة الموجودة نماذج تدريبية، وليست جميع صفحات التصحيح الرسمية.
- لا يحتوي المشروع على إعلانات أو اتصال خارجي مطلوب لتشغيل الدروس.
